# Zolna | زولنا

A curriculum and learning-platform project for Sudanese children in the diaspora, starting with ages 4–8. Zolna aims to connect children with Arabic, Quran, Seerah, and Sudanese language and culture.

## Current status

**Early-stage planning and marketing prototype.** The repository contains an Arabic feasibility-study draft, a bilingual HTML website concept, a development roadmap, and contribution guidance. The website is not a working learning application: recording, pronunciation assessment, interactive lessons, accounts, payments, and offline support are not implemented. No completed curriculum unit, family pilot results, or adoption analytics were supplied for this review.

Ahmed Mohamed ([@Wdaldahab](https://github.com/Wdaldahab)) maintains this project.

## Run the website concept

Download or clone this repository and open `prototypes/zolna-website.html` in a browser. No build step is needed. The language button changes Arabic/English text and page direction; section links navigate within the page. Some action, policy, and social links are placeholders. The microphone illustration does not record audio. Google Fonts is an external dependency; offline functionality is not established.

Static review checked JavaScript syntax and internal anchor targets. Interactive browser testing has not yet been completed.

## Planned learning experience

- Arabic letters and sounds through age-appropriate activities.
- Quran listening and repetition, and stories and values from Seerah, with qualified content review.
- Sudanese words, stories, traditions, and family participation.
- A simple accessible interface with Arabic and English support.

These are development goals, not claims of completed functionality or validated educational outcomes.

## Document organization

Plans are in `docs/planning/` and demonstrations in `prototypes/`. Reviewed lessons will go in `curriculum/` and sourced resource guides in `research/` when available. Zolna is the current project name.

The supplied batch had ten files but four distinct byte-level originals. Repeated PDFs were identical to one another, as were repeated Word files. One public Markdown study and one HTML source are maintained here; original attachments were preserved separately. See the review for details.

## Contribute

Educators, Arabic speakers, Sudanese community members, designers, and developers can suggest improvements through issues and pull requests. Read [CONTRIBUTING.md](CONTRIBUTING.md). Use fictional learner examples and do not upload children’s personal information, family records, credentials, or private contact details.
