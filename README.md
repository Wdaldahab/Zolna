# Zolna | زولنا

A curriculum and learning-platform project for Sudanese children living in the United States.

## Purpose

Zolna aims to help families connect children with Arabic language and Sudanese cultural heritage through accessible, age-appropriate learning resources.

## Current status

**Early planning stage.** This repository currently contains project documentation. Curriculum documents and website prototypes still need to be imported and reviewed. A working learning application, validated curriculum, public release, and adoption metrics are not yet established. Planned features below are goals, not completed functionality.

## Project owner

Ahmed Mohamed ([@Wdaldahab](https://github.com/Wdaldahab)) maintains this repository and coordinates its development.

## Planned learning experience

- Arabic language activities appropriate to learners’ ages and starting levels.
- Sudanese stories, cultural heritage, and family participation.
- A simple, accessible website supporting Arabic and English.
- Small lesson pilots reviewed with educators and families before broader use.

These content folders will be added as reviewed material becomes available. Keep one editable source per document and clearly named PDF exports where needed. Older materials may use the working name “Zool”; Zolna is the current project name.

## How to help

Educators, Arabic speakers, Sudanese community members, designers, and developers can suggest improvements through issues and pull requests. Read [CONTRIBUTING.md](CONTRIBUTING.md) first. Useful feedback includes age suitability, language accuracy, cultural representation, accessibility, and technical implementation.

## Responsible development

Do not submit children’s names, photographs, contact details, learner records, credentials, or private family information. Use fictional examples in prototypes. Referenced resources remain subject to their owners’ terms; link to third-party materials unless redistribution rights are confirmed.

## Licensing

A software and curriculum license has not yet been selected. Public visibility does not itself grant permission to reuse these materials. Licensing must be resolved before describing Zolna as licensed open-source software or an open educational resource.
